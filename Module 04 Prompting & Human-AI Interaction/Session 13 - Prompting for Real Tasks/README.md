# Session 13 - Prompting for Real Tasks

> **Track A (Grades 5-8)** | **Module 4** | **Session 13 of 25**

---

## Overview

Session 13 applies the prompting skills developed in Sessions 11 and 12 to
practical tasks.

The session moves from learning prompting techniques to selecting and
structuring prompts for different situations, including creative work,
everyday tasks, research, learning, and writing.

---

## Purpose

The session is designed to help learners:

- Apply prompting skills to practical tasks
- Identify different types of tasks where AI can help
- Match tasks with appropriate AI tools
- Create prompts for real-world situations
- Test and improve prompts
- Consider responsible use of AI when completing tasks

## Session Construction

The session progresses through the following sequence:

**Recap → Connect → Categorize → Match → Practice → Test → Evaluate → Extend**

### Recap

The session revisits the advanced prompting techniques introduced in
Session 12.

### Connect

Learners consider practical situations where they might want AI assistance
rather than treating prompting as an isolated skill.

### Categorize

Different types of tasks are explored, including:

- Creative tasks
- Everyday tasks
- Research tasks
- Learning tasks
- Writing tasks

### Match

Learners consider which AI tool is appropriate for a particular task and what
kind of prompt could be used.

### Practice

Learners create prompts for practical tasks and apply the techniques they
have learned.

### Test

Learners test their prompts, examine the responses, and make improvements.

### Evaluate

A four-question test is used to help learners think about whether an AI
response is useful and appropriate.

The session also addresses responsible use when applying AI to real tasks.

### Extend

The **Helper Week** activity and full-pipeline challenge give learners an
opportunity to apply prompting across multiple practical situations.

- Writing

Learners consider how the task, tool, and prompt work together.

---

## Hands-On Component

**Real-Task Prompting Playground**

Learners select practical tasks and:

1. Identify the task
2. Select an appropriate AI tool
3. Create a prompt
4. Test the prompt
5. Review the response
6. Improve the prompt
7. Evaluate the result

The activity moves prompting from a technique practiced in isolation to a
skill used for completing actual tasks.

---

## Reflection

Learners reflect on:

- Which prompts produced useful results
- How they improved their prompts
- Which AI tools were appropriate for different tasks
- Whether the AI response was actually useful
- How AI should be used responsibly

---

## Assessment & Extension

The session includes practical prompting activities, tool-matching exercises,
prompt testing, evaluation, discussion, and reflection.

The **Helper Week** activity provides an opportunity to use AI for practical
tasks over a period of time.

The full-pipeline challenge asks learners to apply prompting from identifying
a task through producing and evaluating the final result.
