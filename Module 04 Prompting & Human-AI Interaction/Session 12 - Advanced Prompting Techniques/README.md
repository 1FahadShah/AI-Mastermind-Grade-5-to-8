# Session 12 - Advanced Prompting

> **Track A (Grades 5-8)** | **Module 4** | **Session 12 of 25**

---

## Overview

Session 12 builds on the basic prompting skills introduced in Session 11 by
introducing more advanced ways to structure prompts and guide AI responses.

The session gives learners opportunities to experiment with different
prompting techniques and observe how changes in the prompt affect the output.

---

## Purpose

The session is designed to help learners:

- Move beyond basic prompts
- Explore different prompting techniques
- Understand how roles and examples can guide AI responses
- Experiment with different prompt structures
- Combine prompting techniques for different tasks
- Test and improve prompts based on the resulting output

## Session Construction

The session progresses through the following sequence:

**Recap → Introduce → Demonstrate → Experiment → Combine → Practice → Reflect → Extend**

### Recap

The session revisits the basic prompting ideas from Session 11 and the
importance of giving AI clear instructions.

### Introduce

Learners are introduced to advanced prompting techniques and how different
prompt structures can influence an AI response.

### Demonstrate

The techniques are demonstrated through examples so learners can compare
different approaches to the same task.

### Experiment

Learners test different prompting techniques and observe how the responses
change.

### Combine

Learners experiment with combining techniques to create more directed
prompts for specific tasks.

### Practice

A prompt playground gives learners an opportunity to create, test, and revise
their own prompts.

### Reflect

Learners consider which techniques produced useful results and how changing
the prompt affected the AI's response.

### Extend

The session prepares learners to apply prompting techniques to practical,
real-world tasks in Session 13.

## Examples & Explanations

The session uses examples to compare different prompting approaches and show
how the same AI system can produce different responses depending on how the
request is structured.

Learners examine the effect of providing roles, examples, and additional
instructions.

---

## Hands-On Component

**Prompt Playground**

Learners experiment with different prompting techniques by:

1. Writing a prompt
2. Testing the prompt
3. Observing the response
4. Changing the prompting technique
5. Comparing the results
6. Refining the prompt

The activity provides direct practice with advanced prompt construction.

---

## Reflection

Learners reflect on:

- Which prompting techniques produced useful results
- How different instructions changed the response
- When a particular technique might be useful
- What happened when multiple techniques were combined

---

## Assessment & Extension

The session includes demonstrations, prompt experiments, comparison activities,
hands-on practice, and reflection.

A character-based prompting challenge provides an additional opportunity to
apply the techniques introduced in the session.
