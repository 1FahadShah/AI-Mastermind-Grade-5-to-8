# Session 15 - Computer Vision

> **Track A (Grades 5-8)** | **Module 5** | **Session 15 of 25**

---

## Overview

Session 15 introduces Computer Vision as a field of AI that works with visual information.

The session explores how AI systems use images and visual clues to detect objects, identify patterns, and make predictions. Learners connect these ideas to applications such as self-driving systems, medical imaging, social media filters, and agriculture.

---

## Purpose

The session is designed to help learners:

- Understand what Computer Vision means
- Explore how AI works with visual information
- Identify common Computer Vision applications
- Understand how visual clues can be used to make predictions
- Explore the relationship between visual input, patterns, predictions, and actions
- Apply Computer Vision concepts to practical scenarios

## Session Construction

The session progresses through the following sequence:

**Warm-Up → Define → Explore → Model → Identify → Apply → Analyze → Reflect**

### Warm-Up

Learners consider how they recognize and interpret objects around them using visual information.

### Define

Computer Vision is introduced as AI that works with images and other visual information.

### Explore

Learners examine Computer Vision applications, including:

- Self-driving systems
- Medical imaging
- Social media filters
- Agriculture
- Security

### Model

The session introduces a simplified Computer Vision flow:

**Pixels / Visual Input → Detect Features → Find Patterns → Make a Prediction → Take Action**

This provides a simple way to understand how a Computer Vision system can process visual information.

### Identify

Learners examine visual clues that an AI system might use to identify objects or situations.

### Apply

Learners work through a self-driving scenario involving:

- Stop signs
- Pedestrians
- Red traffic lights

They consider what visual information an AI system could detect and what action could follow.

### Analyze

Learners explore how social media filters can use visual information to detect faces and identify relevant visual features.

### Reflect

Learners consider how Computer Vision differs from human vision and why visual information alone may not always be enough to make a correct decision.

## Hands-On Component

**Self-Driving Vision Activity**

Learners analyze a simplified self-driving scenario and consider:

1. What visual information is available
2. Which objects or features an AI system needs to detect
3. What patterns may help identify the situation
4. What prediction the system could make
5. What action could follow

Scenarios include identifying a stop sign, pedestrian, or red traffic light.

The activity connects Computer Vision concepts to the **visual input → features → patterns → prediction → action** flow introduced in the session.
