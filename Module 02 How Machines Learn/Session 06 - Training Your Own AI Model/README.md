# Session 06 - Training Your Own AI Model

> **Track A (Grades 5-8)** | **Module 2** | **Session 6 of 25**

---

## Overview

Session 06 gives learners a practical introduction to training and testing a
Machine Learning model.

The session builds on the data, features, training, testing, and overfitting
concepts from Session 05 through a hands-on Cats vs Dogs classification
activity.

Learners experiment with different amounts of training data and different
numbers of training epochs, then compare how the model performs on new
examples.

---

## Purpose

The session is designed to help learners:

- Train a simple Machine Learning model
- Understand the relationship between training data and model performance
- Compare models trained with different amounts of data
- Understand the basic idea of an epoch
- Observe how training can affect a model's performance
- Recognize that more training is not always better
- Connect model experiments back to data quality and generalization

## Session Construction

The session progresses through the following sequence:

**Recap → Build → Experiment → Compare → Explain → Reflect → Extend**

### Recap

The session revisits the role of data, features, training, testing, and
overfitting from Session 05.

### Build

Learners work with a Cats vs Dogs classification task and train a Machine
Learning model using Teachable Machine and a dataset from Kaggle.

### Experiment

Learners change the amount of training data and compare different training
conditions:

- 1 photo per class
- 10 photos per class
- Around 100 photos per class
- 1 training epoch
- 50 training epochs

### Compare

Learners test the resulting models on new images and compare how their
performance changes as the training setup changes.

### Explain

The session introduces the idea that more varied examples can help a model
learn patterns that generalize to new examples.

The concept of an **epoch** is also introduced as one complete pass through
the training examples.

### Reflect

Learners consider why a model can perform differently depending on its data
and training setup, including how excessive training can contribute to
overfitting.

### Extend

Homework asks learners to find a dataset and consider what an AI system
could learn from it and what could go wrong.

## Examples & Explanations

The Cats vs Dogs classifier provides the main example for the session.

Learners compare a model trained with very small amounts of data against
models trained with more examples.

The session also uses a simplified comparison between the scale of the
classroom experiment and real AI systems, including differences in dataset
size, training time, and model performance.

---

## Hands-On Component

**Tools:** Teachable Machine and Kaggle

Learners train and test a Cats vs Dogs classifier through multiple
experiments.

The experiments change:

- The number of training images
- The number of training epochs

Learners then test the models using new images and compare the results.

---

## Reflection

Learners discuss:

- What changed when more training images were used
- Why variety in training examples matters
- What happened when the model was trained for more epochs
- How overfitting can affect a model
- Why testing with new examples matters

---

## Assessment & Extension

The session includes model-training experiments, comparison of results,
discussion, and reflection.

Homework asks learners to find a dataset and identify:

- What data it contains
- What an AI system could learn from it
- What could go wrong when using the data
