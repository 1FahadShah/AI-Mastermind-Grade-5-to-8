# Session 04 - Types of Machine Learning

> **Track A (Grades 5-8)** | **Module 2** | **Session 4 of 25**

---

## Overview

Session 04 introduces three common types of Machine Learning:

- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

The session builds on the idea of machines learning from patterns and
introduces how different learning approaches use different types of feedback.

---

## Purpose

The session is designed to help learners:

- Understand the basic idea behind supervised learning
- Understand the basic idea behind unsupervised learning
- Understand the basic idea behind reinforcement learning
- Compare the three learning types
- Recognize examples of each type in real-world AI systems
- Identify which type of learning may be involved in different applications

## Session Construction

The session progresses through the following sequence:

**Recap → Introduce → Explain → Compare → Apply → Analyze → Extend**

### Recap

The session connects back to the idea of Machine Learning introduced in
Session 03 and revisits how machines can learn patterns from examples.

### Introduce

The three learning types are introduced as different ways a machine can learn
from data and feedback.

### Explain

Each learning type is explained separately:

- **Supervised Learning** - learning from labeled examples or answer keys
- **Unsupervised Learning** - finding patterns or groups without provided
  answers
- **Reinforcement Learning** - learning through trial and error using rewards
  and penalties

### Compare

A cookie-based analogy is used to help distinguish the three learning
approaches.

The session also compares them using factors such as the type of data, goal,
and feedback available during learning.

### Apply

Learners classify different AI examples according to the type of Machine
Learning involved.

Examples include image classification, photo organization, recommendation
systems, and other familiar applications.

### Analyze

Learners examine real-world examples such as Spotify and Netflix and consider
how different learning approaches can be used in AI systems.

### Extend

Homework asks learners to find one example of each learning type.

A stretch activity asks learners to find an application that uses at least
two types of Machine Learning.

## Examples & Analogies

The session uses a cookie-based analogy to distinguish the three learning
types.

Real-world examples include:

- Spotify
- YouTube
- Google Maps
- Face Unlock
- ChatGPT
- Netflix

These examples are used to connect the learning types to AI systems learners
may already recognize.

---

## Hands-On Component

The session includes classification and analysis activities.

Learners examine different AI applications and determine which Machine
Learning approach best describes how the system could learn.

They also analyze a real-world recommendation system and discuss what data it
could use, what it is doing with that data, and what it might predict.

---

## Reflection

Learners compare the three learning types and consider:

- What kind of data each approach uses
- Whether answers are provided
- What kind of feedback is available
- How the approaches differ in the way they learn

---

## Assessment & Extension

The session includes comparison activities, application classification,
discussion, and real-world AI analysis.

Homework asks learners to identify one example of supervised learning, one
example of unsupervised learning, and one example of reinforcement learning.

A stretch challenge asks learners to identify an application that uses at
least two learning types.
