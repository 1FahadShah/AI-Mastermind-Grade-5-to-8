# Session 03 - What is Machine Learning?

> **Track A (Grades 5-8)** | **Module 2** | **Session 3 of 25**

---

## Overview

Session 03 introduces Machine Learning as a way for computers to learn
patterns from examples instead of following rules written by a person.

The session builds on the AI concepts from Module 01 and prepares learners
to explore the different ways machines can learn in Session 04.

---

## Purpose

The session is designed to help learners:

- Define Machine Learning in their own words
- Distinguish between rules-based and learning-based systems
- Understand why fixed rules cannot solve every problem
- Recognize patterns in examples
- Understand how Machine Learning uses patterns to work with new data
- Observe a Machine Learning model learning from examples

## Session Construction

The session progresses through the following sequence:

**Recap → Connect → Explain → Compare → Practice → Demonstrate → Reflect → Extend**

### Recap

The session begins by revisiting the AI Detective homework from Session 02
and reviewing the **AI Recipe**:

**Data → Algorithm → Training → Model → Prediction**

### Connect

Learners compare two ways of learning through a familiar question:

How did they learn what a dog looks like - by following a rulebook or by
seeing many examples?

This introduces the idea of learning from experience and patterns.

### Explain

Machine Learning is introduced as computers learning patterns from examples
instead of following rules written by a person.

### Compare

Rules-based systems are compared with learning-based systems using familiar
examples such as calculators, traffic lights, microwaves, YouTube
recommendations, Gmail spam filters, face unlock, and Netflix suggestions.

### Practice

Learners identify patterns in number, shape, and everyday examples through
short pattern-recognition activities.

### Demonstrate

Google Teachable Machine is used to show a Machine Learning model learning
from examples of hand gestures.

### Reflect

Learners examine how the model learned, what patterns it recognized, and how
Machine Learning differs from fixed rules.

### Extend

Homework asks learners to identify Machine Learning systems they use and
describe the patterns they think those systems learn.

---

## Examples & Explanations

The session contrasts traditional rule-based systems with Machine Learning.

A spam filter is used to show why writing fixed rules for every possible
variation can become difficult.

Pattern-recognition activities are then used to demonstrate the basic idea of
finding repeated patterns in examples.

---

## Hands-On Component

**Tool:** Google Teachable Machine

The session uses Teachable Machine as a live demonstration rather than a full
model-building activity.

Learners observe a model being shown examples of:

- Peace sign
- High five
- Fist

The activity demonstrates how a model can learn patterns from examples and
recognize new examples.

The actual model-building activity is introduced later in the program.

---

## Reflection

Learners discuss:

- How the model learned from examples
- What patterns it recognized
- How learning-based systems differ from fixed rules
- Where Machine Learning appears in everyday life

---

## Assessment & Extension

The session includes recap questions, pattern-recognition activities,
classification of rules-based and learning-based systems, discussion, and a
Teachable Machine demonstration.

The homework asks learners to identify three Machine Learning applications,
describe what each one does, and explain what patterns they think the systems
learn.
