# Module 02 - How Machines Learn?

> **Track A (Grades 5-8)** | **Module 2 of 8** | **Sessions 3-6** | **4 Hours**

---

## Overview

Module 02 introduces learners to Machine Learning and how machines learn
patterns from data.

The module moves from the basic idea of Machine Learning into different
learning types, the role of data, and practical model training.

Learners progress from recognizing how Machine Learning works to training and
testing a simple classification model.

---

## Module Purpose

The module is designed to help learners:

- Understand Machine Learning as learning patterns from examples
- Distinguish learning-based systems from fixed rule-based systems
- Understand supervised, unsupervised, and reinforcement learning
- Understand the role of data and features
- Distinguish training data from testing data
- Understand generalization and overfitting
- Recognize how data quality, variety, and bias can affect AI systems
- Train and test a simple Machine Learning model

## Session 03 - What is Machine Learning?

The first session introduces Machine Learning as a way for computers to learn
patterns from examples instead of relying only on rules written by a person.

Learners compare rules-based and learning-based systems, explore pattern
recognition, and observe a Machine Learning model learning from examples.

---

## Session 04 - Types of Machine Learning

The second session introduces three common types of Machine Learning:

- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

Learners compare how the three approaches use data and feedback and classify
different real-world AI applications.

---

## Session 05 - How AI Learns from Data

The third session focuses on the role of data in Machine Learning.

Learners explore datasets, features, training and testing data,
generalization, overfitting, limited data, bias, and data quality.

A planning activity uses a hypothetical Healthy / Unhealthy Food AI to examine
how data choices can affect an AI system.

---

## Session 06 - Training Your Own AI Model

The final session turns the concepts from the previous sessions into a
hands-on model-training activity.

Learners train and test a Cats vs Dogs classifier using Teachable Machine
and Kaggle.

They experiment with different amounts of training data and different
numbers of training epochs, then compare the results.

---

## Design Approach

The materials in this module use a progression from concept introduction to
practical experimentation.

Across the four sessions, learners:

- Explore Machine Learning through familiar examples
- Compare different approaches to learning
- Examine the role of data and features
- Analyze problems such as overfitting and bias
- Work with real AI tools
- Train and test a simple model
- Reflect on experimental results
- Extend learning through homework and follow-up tasks

The hands-on work becomes progressively more direct, moving from observing
Machine Learning in Session 03 to training and testing a model in Session 06.

---

## Hands-On Work

The module includes practical activities using:

### Teachable Machine

Used to demonstrate Machine Learning and later train and test a Cats vs Dogs
classification model.

### Kaggle

Used as a source of dataset material for the model-training activity.

The module also includes analysis and planning activities involving AI
systems, data, features, and potential model failures.

---

## Assessment & Extension

Assessment and extension activities are included at the session level.

Across the module, learners engage with:

- Recap questions
- Pattern-recognition activities
- Classification activities
- Real-world AI analysis
- Data and feature analysis
- Model-training experiments
- Reflection and discussion
- Homework and extension tasks

The extension tasks progressively move learners from identifying Machine
Learning applications to analyzing data and planning for potential model
problems.

---

## Module Connection

Module 02 builds directly on the AI terminology introduced in Module 01.

It provides the Machine Learning foundation needed for the next stage of the
program, where learners move into Generative AI and modern AI models.
